# Email Scheduler — Frontend

React + TypeScript + Vite dashboard for the SCHEDULER backend.

Schedule future emails, track status, search sent content, and view summary stats.

## Run

Backend must be running first (see `backend/`). Vite proxies `/api` to `http://localhost:5001`.

```
npm install
npm run dev
```

Open `http://localhost:5173`.

## Build

```
npm run lint
npm run build
```
